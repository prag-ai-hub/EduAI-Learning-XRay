# EduAI Learning XRay - Version 25

Released: 25 August 2026

## AI Grading workflow

- Analyse Assessment now starts AI Grading for the selected answer sheet.
- Check Multiple Students queues AI Grading for the selected students.
- OCR continues in the background and is not presented for review at this workflow entry point.
- When grading completes, teachers are taken to the existing Review tab to review AI-graded answer sheets.
